TEPHRA: a volcanic-ash decision desk

When the official ash reports disagree, TEPHRA keeps the wider area, finds the flights heading in and drafts the advisory a dispatcher approves.

  • Decision support only
  • Ring of Fire Air (RFA) is a fictional airline
  • Nothing is sent to an aircraft or any real system
  • REPLAY plays recorded real feeds

How it works
  1. Public feeds
  2. Code labels every disagreement
  3. The Coordinator orders the work
  4. The Plume reader proposes the area
  5. Code keeps the official floor and finds the flights
  6. The Flight planner and Drafter write a draft
  7. A person decides on the Desk
  8. Every step goes into the hash-chained record

The operator must resolve those conflicts (ICAO Doc 9974). TEPHRA drafts that reconciliation for the dispatcher to check.

The public demo runs on Google Cloud: Cloud Run (Singapore), Cloud Scheduler, Firestore, Secret Manager, Artifact Registry; the Gemini API and the Agent Development Kit.
